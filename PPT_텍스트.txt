--------------------------------------------------------------------------------
[S1] 1.1 개발 배경
--------------------------------------------------------------------------------
  국내 65세 이상 1인 가구 200만 세대 초과 · 고독사 증가 추세

  기존 안전 확인 수단의 한계
    CCTV·카메라     사생활 침해 → 침실·화장실 설치 불가
    웨어러블        착용 순응도 낮음 (수면 중·목욕 중 미착용)
    PIR 동작감지    움직임 유무만 판별 → 수면 정지와 의식 소실 구분 불가
    응급호출 버튼   의식이 없으면 누를 수 없음

  → 세 번째가 본 프로젝트의 출발점
     "장시간 무동작"을 위급 신호로 삼으면 매일 밤 오탐 → 사용자가 알림을 끔

--------------------------------------------------------------------------------
[S2] 1.2 개발 동기
--------------------------------------------------------------------------------
  CSI(Channel State Information)
    WiFi 수신 칩이 통신을 위해 이미 계산하는 부반송파별 진폭·위상 데이터
    별도 센서 없이 공간 내 물리적 변화 관측 가능

  핵심 아이디어
    수면 중에도 흉곽은 분당 12~20회 미세하게 움직인다

    정상 수면  =  큰 움직임 없음  +  호흡 주기성 있음
    위급 상황  =  큰 움직임 없음  +  호흡 주기성 없음

  → PIR이 원리적으로 구분할 수 없던 두 상태를 분리

--------------------------------------------------------------------------------
[S3] 1.3 개발 목표
--------------------------------------------------------------------------------
  핵심   카메라·웨어러블 없이 WiFi 신호만으로 재실·호흡 판별
         수면 시간대 호흡 신호 지속 소실 시 로컬 알림(LED·부저)

  부가1  ESP32 단독 standalone edge 시스템 (호스트 PC는 개발·디버깅 전용)
  부가2  공간·사용자별 임계값 자동 보정 적응형 알고리즘

  비목표 심박수 측정 · 낙상 '순간' 포착 · 다인/다공간 대규모 검증
         (1주 프로토타입 기간 내 신뢰성 확보 불가로 명시적 제외)

--------------------------------------------------------------------------------
[S4] 1.4 개발 필요성
--------------------------------------------------------------------------------
  1) 프라이버시 보존   영상·음성 미수집, 무선 신호 왜곡 계수만 수집
                       CCTV 설치가 막힌 침실에도 적용 가능
                       ※ CSI 기반 간접 식별 가능성은 별도 연구 영역이며
                          원천 차단을 주장하지는 않음
  2) 인프라 유연성     공유기 있으면 비콘 재활용(RX만 설치)
                       공유기 없으면 TX/RX 폐쇄망 자체 구성
  3) 온디바이스        신호처리·판정·알림 전부 로컬, 클라우드 전송 경로 없음
  4) 저비용            부품비 약 2만원

--------------------------------------------------------------------------------
[S5] 1.5 유사 사례 비교
--------------------------------------------------------------------------------
  (1) 지자체 PIR 감지등  예: 진천군 2020, 예산 1억원 / 220가구
      8·12·24시간 무동작 → 주의·경보·위험
      8시간 지연은 설계 실수가 아니라 PIR의 원리적 한계의 결과

  (2) 보건복지부 응급안전안심서비스  전국 단위 국가 서비스
      레이더센서로 심박·호흡 측정 → 본 시스템과 목표가 가장 근접
      차이는 센싱 매체: 전용 레이더 3만~15만원 vs WiFi 칩 3천~7천원

  (3) 상용 홈케어 허브  동작감지 + 충격감지 태그 + 비상벨
      충격·의식·조작 중 하나를 반드시 요구 · 태그는 착용형

  종합: 세 사례 모두 낙상/충격/의식/조작을 요구하거나 장시간 타임아웃에 의존
        본 시스템의 기여는 "새로운 감지 원리"가 아니라
        "동일 기능을 훨씬 저렴한 범용 부품으로 재현"

[S6] 2.1 하드웨어
--------------------------------------------------------------------------------
  ESP32-WROOM-32 개발보드(38핀) x2    TX(송신) / RX(수집·판정·알림)
  브레드보드 830핀, 수동형 부저, LED(적색)+220옴, 점퍼 와이어 x6
  총 부품비 약 2만원

  물리 구성 (하이브리드)
    호흡 감지   TX ~~2.4GHz WiFi~~> RX      초당 11~13 패킷, 인체 반사·회절
    재실 판정   거주자 스마트폰 → RX        AP 결합 목록 조회 (10초 주기)

  GPIO 결선
    GPIO4  LED(+220옴 직렬)     디지털 HIGH/LOW
    GPIO5  수동형 부저          LEDC PWM 2,700Hz duty 50%
    GPIO0  등록 버튼(BOOT 재활용)

  실측 유효 감지 거리 TX-RX 약 1~2m

--------------------------------------------------------------------------------
[S8] 2.3 기능 설계도 (전 과정 ESP32 내부)
--------------------------------------------------------------------------------
  WiFi task ──(CSI callback: memcpy만)──> xQueue ──> CSI task ──> ring buffer
                                                                       │
                                                        Decision task ─┘ (10초)

  원시 CSI(52 서브캐리어 I/Q)
    → 선별 8개 power = I²+Q² (sqrt 생략)
    → 100ms 시간 빈 → 균일 10Hz 스트림
    → 256 샘플 링버퍼 (25.6초 창)
    → 최소자승 직선 추세 제거
    → 0.2~0.5Hz IIR 대역통과 (RBJ biquad)
    → Goertzel 뱅크 7개 빈 → 피크 주파수 + 스펙트럼 집중도
    → 주파수 일관성 확인(최근 3창) → 상태 판정 + 히스테리시스
    → LED / 부저

--------------------------------------------------------------------------------
[S9] 2.3 기능 설계도 – 상태 판정 분기
--------------------------------------------------------------------------------
                        움직임 감지
                   ┌──────────────────────> ACTIVE
                   │
     윈도우 ───────┤  움직임 없음
                   │
                   v
           호흡 주기성 있는가?
              │            │
             YES          NO
              │            │
              v            v
        SLEEP_NORMAL   NO_RESPONSE
                           │
                 60초 지속 AND 수면시간대?
                           │
                          YES
                           │
                 재실 확인 (3.4절)
                   아래 중 하나라도 "외출"이면 억제
                     · 스마트폰이 AP에 결합되어 있는가?  [주 신호]
                     · CSI 이탈 버스트가 관측되었는가?   [보조 신호]
                           │
                      재실 확정 ──> EMERGENCY (LED + 부저)

     데이터 자체가 없으면(NO_DATA) 60초 지속 시 ──> FAULT (LED만, 부저 없음)

--------------------------------------------------------------------------------
[S12] 3.3 기술적 차별성 (1)~(4)
--------------------------------------------------------------------------------
  (1) 호흡 주기성을 이용한 무동작의 이원 분해
        ACTIVE / SLEEP_NORMAL / NO_RESPONSE 3상태
        PIR로는 원리적으로 2·3행 구분 불가

  (2) 임베디드 환경에 맞춘 신호처리 재설계
        범용 Welch/FFT 이식 대신 관심 대역만 계산하는 Goertzel
        정직한 평가: 곱셈 약 1,792회 vs 256점 FFT 약 4,096회 → 2~3배 수준
        실질 이점: 복소 버퍼 불필요 / 정확한 주파수 배치 / 외부 DSP 무의존

  (3) 데이터 축소 설계
        창당 23kB → 스칼라 압축 후 링버퍼 256 float(1kB)
        power(I²+Q²) 사용, sqrt 생략

  (4) 다층 오탐 억제  (단일 윈도우 오탐 18% 실측 근거)
        a. 선형 추세 제거 (저주파 드리프트 누설 차단)
        b. 주파수 일관성 (최근 3창 ±0.12Hz 일치 시에만 확정)
        c. 히스테리시스 (연속 6회 = 60초 지속 시 발동)

--------------------------------------------------------------------------------
[S13] 3.3 기술적 차별성 (5)~(7)
--------------------------------------------------------------------------------
  (5) 시공간 맥락 인지
        동일한 NO_RESPONSE도 시각에 따라 의미가 다름
        수면 시간대(22시~7시)에만 응급 알림 활성화

  (6) 센서 고장과 사람 이상의 분리   [실기 테스트로 발견·수정]
        초기: NO_DATA와 NO_RESPONSE를 단일 카운터로 처리
        실기: TX 전원 차단 시 60초를 채워 응급 부저 발동
        수정: ALERT_EMERGENCY (LED+부저, 수면시간대 한정)
              ALERT_FAULT     (LED만, 시간대 무관)

  (7) 적응형 임계값 자동 보정
        기기는 임계값을 학습하지 않는다. 정지 baseline만 학습
            움직임 판정 ⟺ rssi_std > mu_still + K × sigma_still   (K = 3.0)
        이점: NVS 저장값 실수 2개 / 부트스트랩 후 EWMA(시정수 약 80분)
              이상 상태에서는 baseline 갱신 금지 (경보 자기무력화 방지)

--------------------------------------------------------------------------------
[S14] 3.4 재실 판정과 호흡 감지의 신호원 분리 – 설계안 비교
--------------------------------------------------------------------------------
  최대 미해결 과제: "외출"과 "응급"이 CSI 상에서 동일하게 NO_RESPONSE

  A안  CSI 2-zone (침실/현관 RX 2대)                            [폐기]
       ESP32는 미결합 상태에서 타 BSS 유니캐스트의 CSI를 산출 못함
       (30cm 거리에서도 20초간 콜백 1~2회) → 4.7절

  B안  스마트폰을 CSI 송신원으로 사용                           [폐기]
       호흡 대역 유지에 폰 WiFi 절전 차단 필요 → 배터리 소모 급증
       독거노인의 폰 방전은 그 자체가 안전 위험
       → 트레이드오프가 아닌 설계 결함으로 판단

  C안  하이브리드 – 신호원 분리                                 [채택]
       호흡 감지: 전용 TX(또는 공유기 비콘), 상시 급전 기기가 송신 부담
       재실 판정: 폰의 AP 결합 여부만 조회, 폰에 추가 부하 0

--------------------------------------------------------------------------------
[S15] 3.4 재실 판정 – 4단 축퇴 구조와 자동 채택 규칙
--------------------------------------------------------------------------------
  4단 축퇴 (구체적일수록 우선, 각 단계는 다음 단계로 축퇴)
    1단 PINNED      빌드 시 MAC 지정. 무작위 MAC 정책에 취약
    2단 REGISTERED  설치 시 1회 등록(BOOT 버튼 또는 REGISTER 명령)
    3단 ADOPTED     자동 학습. 거주자 조작 불필요
    4단 ANY         자격 단말이 하나라도 결합 시 재실 (폐쇄망이므로 성립)

  자동 채택 규칙 – "오래 붙어있는 기기"가 아니라 "드나드는 기기"
    ✗ 존재 빈도 기준 → TV·거치 태블릿 선택 → 영구 재실 → 경보 무력화
    ✓ 이탈·복귀 3회 이상 관측된 단말만 인정
    복수 후보 시 이탈 횟수 최다 단말 채택 (선착순 아님)

  등록 절차 – 애매하면 추측하지 않고 거부
    창 종료 시 신규 결합이 정확히 1대일 때만 등록, 2대 이상이면 거부 후 목록 출력
    (실기에서 오등록 재현 → 거부 로직으로 수정 → REGISTER <MAC> 수단 추가)

  모든 단계에서 불확실하면 "재실"로 판정 (경보 유지 방향이 안전)

[S17] 4.1 ~ 4.3

      진단 방법론: 시리얼 포트 개방 자체가 보드를 리셋시킴
                   → 짧게 여러 번보다 한 번에 길게(90초 이상) 관찰

--------------------------------------------------------------------------------
[S19] 4.7 미결합 상태의 CSI 취득 실패 (2-zone 확장 시도 폐기)
--------------------------------------------------------------------------------
  시도    재실 판별용 2-zone 구성. 두 번째 RX를 promiscuous 모드로 운용

  증상    30cm 거리에서도 CSI 콜백 20초간 1~2회
          (정상 RX는 같은 시간 약 110회)

  진단    promiscuous raw 콜백으로 확인 → 일반 패킷은 20초에 1.3MB 수신
          즉 전파는 도달하나 CSI만 산출되지 않음

  해석    ESP32의 CSI 추출 경로는 자신이 속한 BSS의 프레임에만 실질 동작
          passive 예제는 비콘 등 브로드캐스트를 전제한 것으로 판단

  결론    2-zone CSI 확장 폐기 → 재실 판정을 폰 결합 조회로 재정의(3.4절)
          단순 후퇴가 아니라 "재실 판정에 CSI가 불필요"라는 문제 재정의

  기록 가치: ESP32 CSI 문서에 명시되지 않은 제약, 후속 개발에 유용

[S25] 5.4 한계
--------------------------------------------------------------------------------
  1) 감지 범위    TX-RX 유효 거리 약 1~2m → 외장 안테나·다중 노드 필요
  2) 데이터 규모  137 윈도우·단일 피험자 → 통계적 일반화 부족
                  분류기 성능은 개념 증명 수준
  3) RF 간섭      2.4GHz 대역 공유 → 패킷 손실 시 주기성 판정 왜곡 가능
  4) 원격 알림    미구현. 현재 로컬 알림 한정
  5) TX 재결합    AP 재시작 즉시 감지 못함 (재결합 로직 미개선)
  6) 재실 판정    거주자가 외출 시 폰을 소지함을 전제
                  (미소지 시 과잉 경보 방향 → 안전한 실패)
                  등록 결과를 현장에서 확인할 수단은 아직 시리얼 로그뿐
