# 시연 시나리오 (약 5분)

## 사전 준비 (시연 5분 전)
1. AP보드(RX) — LED/부저 배선 확인, Mac에 USB 연결
2. STA보드(TX) — 별도 전원 연결, AP와 가까운 거리(연결 안정성 확인된 거리) 유지
3. 새 펌웨어 필요 없음 — 이미 플래시된 상태로 진행

```bash
get_idf
ls /dev/cu.*
```

**데모용 임계값 완화** (실제 발표 시간이 밤 10시~아침 7시가 아닐 경우 필수):
`live_monitor.py`에서 아래 두 값을 시연 직전 임시로 바꿔서 진행하고, 끝나면 원복합니다.
- `SLEEP_HOUR_START = 0`, `SLEEP_HOUR_END = 24` (시간 제약 해제)
- `NO_RESPONSE_STREAK_REQUIRED = 2` (60초 → 20초로 단축, 시연 시간 절약)

```bash
/opt/anaconda3/bin/python3 ~/Desktop/ESP_project_2026/data/live_monitor.py /dev/cu.usbserial-포트 --label demo
```

## 시연 흐름

**1) 시스템 소개 (30초)**
"이 시스템은 카메라나 웨어러블 센서 없이, 일반 WiFi 전파만으로 사람의 존재와 호흡을 감지합니다. 두 개의 ESP32 보드가 서로 통신하면서, 그 신호가 사람 몸에 부딪혀 어떻게 미세하게 왜곡되는지를 분석합니다."

**2) 평상시 움직임 감지 (30초)**
보드 근처에서 자연스럽게 움직인다.
→ 화면에 `ACTIVE` 상태가 뜨는 것을 보여줌.
"활동 중인 상태는 이렇게 실시간으로 잡힙니다."

**3) 정상 수면 상태 (1분)**
보드 근처에 가만히 누워서 자연스럽게 호흡한다.
→ 화면에 `SLEEP_NORMAL`로 전환되는 것을 보여줌.
"가만히 있어도, 숨쉬는 미세한 움직임이 감지되면 '정상 수면'으로 판단합니다. 이게 이 프로젝트의 핵심입니다 — 단순히 안 움직인다고 위급 상황으로 보지 않는 거죠."

**4) 위급 상황 시뮬레이션 (1~2분)**
자리를 완전히 비운다 (또는 숨을 죽이고 최대한 움직이지 않는다 — 단, 실제로는 자리를 비우는 쪽이 더 확실하고 안전한 시연).
→ `NO_RESPONSE` 상태가 뜨고, streak가 쌓이는 것을 실시간으로 보여줌.
→ streak가 임계값에 도달하면 **LED와 부저가 실제로 작동**.
"호흡 신호가 일정 시간 이상 사라지면, 이렇게 실제 알림이 울립니다. 로컬 알림이라 인터넷이나 스마트폰 없이도 작동합니다."

**5) 복귀 및 알림 해제 (30초)**
다시 보드 근처로 돌아와 눕는다.
→ 상태가 `SLEEP_NORMAL`로 돌아오고 `ALERT_OFF`가 전송되며 LED/부저가 꺼지는 것을 보여줌.

**6) 마무리 — 한계와 확장 (30초)**
"공간마다 감지 민감도가 달라서, 저희는 침대/바닥 등 여러 공간에서 데이터를 모아 임계값을 자동으로 보정하는 시스템도 만들었습니다. 데이터가 더 쌓이면 규칙 기반이 아니라 학습된 분류기로 완전히 전환할 수 있는 구조입니다."
