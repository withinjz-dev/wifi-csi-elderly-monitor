발표자료 초안 (PPT 제작용)
WiFi CSI 기반 비접촉 독거노인 이상감지 시스템 / 팀 시그널보내
제24회 임베디드 소프트웨어 경진대회 자유공모 부문
================================================================================

사용법
  - 슬라이드 1장 = [S#] 블록 하나
  - "제목"은 슬라이드 헤드라인, "핵심"은 한 장에서 반드시 전달할 단 한 문장
  - "본문"은 불릿 후보이며 전부 넣지 말고 발표 시간에 맞춰 취사선택
  - "말할 것"은 슬라이드에 쓰지 않고 구두로 전달할 내용
  - 수치는 모두 개발완료보고서.txt의 실측값. 임의로 반올림하지 말 것
  - 총 15장 / 발표 10분 기준. 시간이 7분이면 S8, S11, S13 생략


================================================================================
1부. 문제 정의 (S1~S4)
================================================================================

[S1] 표지
--------------------------------------------------------------------------------
제목: 숨을 쉬고 있는지, WiFi가 대신 봅니다
부제: 카메라도 웨어러블도 없는 독거노인 이상감지
본문:
  - 팀 시그널보내 / 자유공모 부문
말할 것:
  - 발표 첫 문장은 기술이 아니라 상황으로 시작한다.
    "혼자 사는 어르신이 방에서 움직이지 않습니다. 주무시는 걸까요,
     쓰러지신 걸까요?"


[S2] 문제 - 기존 수단이 못 푸는 단 하나
--------------------------------------------------------------------------------
제목: 움직임이 없다 ≠ 위험하다
핵심: 정지 상태를 '수면'과 '의식 소실'로 나누지 못하는 것이 근본 한계다.
본문:
  표 (4행짜리 비교표로 시각화 권장)
    CCTV/카메라    사생활 침해로 침실·화장실 설치 불가
    웨어러블       착용 순응도 낮음 (수면 중·목욕 중 미착용)
    PIR 동작감지   움직임 유무만 판별 -> 수면과 의식 소실을 구분 못함
    응급호출 버튼  의식이 없으면 누를 수 없음
말할 것:
  - 네 가지 모두 "본인이 의식이 있거나, 몸에 뭘 걸치고 있거나, 카메라를
    허용해야" 동작한다.


[S3] 증거 - 그래서 현장은 8시간을 기다린다
--------------------------------------------------------------------------------
제목: 8시간 무동작 = 경보
핵심: 8시간 지연은 설계 실수가 아니라 PIR의 원리적 한계가 만든 결과다.
본문:
  - 진천군 IoT 감지등 사업 (2020) / 예산 1억원 / 220가구
  - 8시간·12시간·24시간 = 주의·경보·위험
말할 것:
  - 왜 하필 8시간인가? 더 짧게 잡으면 매일 밤 수면 시간마다 오경보가 난다.
    오경보가 반복되면 사람은 알림을 꺼버린다. 즉 PIR로는 짧게 잡을 수가 없다.
  - 이 슬라이드가 우리 프로젝트의 존재 이유다.


[S4] 목표
--------------------------------------------------------------------------------
제목: 60초 안에, 아무것도 걸치지 않고
핵심: 수면과 이상을 '호흡 주기성'으로 가른다.
본문:
  - 정상 수면 = 큰 움직임 없음 + 호흡 주기성 있음
  - 위급 상황 = 큰 움직임 없음 + 호흡 주기성 없음
  - 목표: 8시간 -> 60초, 무접촉·무착용
  - 비목표(명시): 심박수 측정, 낙상 '순간' 포착, 다인·대규모 검증
말할 것:
  - 비목표를 먼저 밝히는 것이 신뢰를 준다. 1주 프로토타입으로 할 수 없는 것을
    할 수 있다고 말하지 않는다.

2부. 접근 방법 (S5~S7)
================================================================================

[S5] 원리
--------------------------------------------------------------------------------
제목: 통신용 데이터로 호흡을 본다
핵심: 별도 센서가 아니라, WiFi 칩이 이미 계산하고 있는 값을 읽는다.
본문:
  - CSI(Channel State Information): 부반송파별 진폭·위상 왜곡 계수
  - 흉곽은 수면 중에도 분당 12~20회, 밀리미터 단위로 움직인다
  - 이 주기성이 0.2~0.5Hz 대역에 남는다
그림 지시:
  - [TX] ~~~전파~~~ [RX] 사이에 사람 실루엣, 전파가 인체에 반사·회절되는 도식
  - 오른쪽에 0.3Hz 부근에 봉우리가 있는 스펙트럼 그래프


[S6] 시스템 구성 - 하이브리드
--------------------------------------------------------------------------------
제목: 호흡은 전파로, 재실은 폰으로
핵심: 서로 다른 질문에는 서로 다른 신호원을 쓴다.
본문:
  - 호흡 감지: 전용 TX(또는 가정 공유기) -> RX가 CSI 취득·판정·알림
  - 재실 판정: 거주자 스마트폰의 AP 결합 여부만 조회 (폰에 부하 0)
  - 전 과정 ESP32 온보드. 서버·클라우드·PC 불필요
그림 지시:
  - 보고서 2.1절 물리 구성도를 그대로 도식화
  - 폰은 점선 화살표(조회)로, TX는 실선 화살표(전파)로 구분해 그릴 것


[S7] 부품비
--------------------------------------------------------------------------------
제목: 2만원
핵심: 같은 원리를 훨씬 싼 부품으로 재현하는 것이 이 프로젝트의 기여다.
본문:
  - ESP32-WROOM-32 개발보드 x2, 부저, LED, 저항, 브레드보드 = 약 2만원
  - 전용 FMCW/mmWave 레이더 모듈: 개당 3만~15만원대
말할 것:
  - 여기서 심사위원이 반드시 물어볼 질문을 선점한다 -> 다음 슬라이드

3부. 차별성 (S8~S9)  ※ 예상 질문 선점 구간
================================================================================

[S8] 이미 있는 것 아닌가? - 정면 대응
--------------------------------------------------------------------------------
제목: 이미 있습니다. 그런데 비쌉니다.
핵심: 새로운 감지 원리가 아니라, 동일 기능의 저비용 재현이 우리의 주장이다.
본문:
  - 보건복지부 응급안전안심서비스(전국): 레이더센서로 심박·호흡 측정
  - 원리는 사실상 동일 (반사파 위상 변화로 호흡 검출)
  - 차이는 센싱 매체: 전용 레이더 칩 vs 통신용 WiFi 칩 재활용
말할 것:
  - 이걸 숨기면 질의응답에서 무너진다. 먼저 인정하고 각도를 바꾸는 게 낫다.
  - "국가가 전국 서비스로 운영한다는 건 이 문제가 진짜라는 증거이고,
     우리는 그걸 1/10 가격으로 할 수 있느냐를 검증했습니다."


[S9] 그래도 남는 구멍 - 우리가 메우는 지점
--------------------------------------------------------------------------------
제목: 쓰러지지 않고 조용히 의식을 잃으면?
핵심: 충격·조작·낙상이 없는 경우가 기존 조합의 사각지대다.
본문:
  표
    동작감지(PIR)   정지 상태를 구분 못함 -> 장시간 타임아웃 의존
    충격감지 태그   낙상 충격이 있어야 감지. 착용해야 동작
    비상벨          의식이 있어야 누를 수 있음
    본 시스템       충격·조작 없이도 호흡 유무를 직접 관측
말할 것:
  - 뇌졸중, 심정지, 저혈당 쇼크는 쓰러지지 않고 앉거나 누운 채 진행될 수 있다.
  - 착용형 태그의 순응도 문제(안 차고 자면 무용지물)도 함께 언급.

4부. 구현과 검증 (S10~S13)
================================================================================

[S10] 온디바이스 신호처리 파이프라인
--------------------------------------------------------------------------------
제목: 25.6초 창을 1kB로
핵심: 자세 복원이 아니라 '주기성 유무'만 물으므로 극단적으로 압축할 수 있다.
본문:
  - 원시 CSI 52 서브캐리어 -> 선별 8개 power -> 100ms 빈 -> 10Hz 스트림
  - 최소자승 추세 제거 -> 0.2~0.5Hz 대역통과 -> Goertzel 7빈 -> 피크 주파수
  - 링버퍼 256 float = 1kB (원시 저장 시 창당 23kB)
  - DRAM 24.6% 사용, 136kB 여유
말할 것:
  - Goertzel을 쓴 이유를 과장하지 말 것. FFT 대비 2~3배 수준이고, 진짜 이점은
    복소 버퍼 불필요 + 정확한 주파수 배치 + 외부 DSP 라이브러리 무의존이다.


[S11] 적응형 보정 - 가설을 기각한 과정
--------------------------------------------------------------------------------
제목: 우리가 처음 내린 결론은 틀렸습니다
핵심: 공간별 임계값 테이블이 아니라 정지 baseline + 공유 상수가 옳은 추상화다.
본문:
  - 1차 관측: 공간별 최적 임계값 5.18배 차이 -> "공간마다 임계값이 달라야 한다"
  - 재검증: Otsu는 움직임 강도에도 좌우된다. 통제 조건만 비교하면 1.47배
  - A안 (mu, sigma 정규화): 편차 5.18 -> 21.84배로 악화. 기각
  - B안 mu_still + k*sigma_still (k=3.0): 편차 1.30배, 정지 오탐 0/69
말할 것:
  - 이 슬라이드는 '실패를 보여주는' 슬라이드가 아니라 '검증 능력을 보여주는'
    슬라이드다. 자기 가설을 데이터로 기각한 사례로 제시할 것.
  - k=3.0을 고른 이유: 정지를 움직임으로 오판하면 streak가 초기화되어 실제
    응급을 은폐한다. 그래서 미탐보다 오탐을 더 위험하게 가중했다.


[S12] 실기 테스트로만 나온 안전 결함
--------------------------------------------------------------------------------
제목: 배터리 나간 송신기가 응급 부저를 울렸다
핵심: 센서 고장과 사람 이상을 같은 카운터로 처리한 것이 설계 결함이었다.
본문:
  - 초기: NO_DATA(센서 실명)와 NO_RESPONSE(사람 이상)가 하나의 카운터
  - 실기에서 TX 전원이 끊기자 60초를 채워 응급 부저 발동
  - 수정: ALERT_EMERGENCY(LED+부저, 수면시간대 한정)
          ALERT_FAULT(LED만, 시간대 무관)
말할 것:
  - 왜 위험한가: 오경보가 반복되면 보호자가 알림 전체를 무시하게 된다.
    이것이 안전 시스템의 가장 위험한 실패 양상이다.
  - 책상 위 시뮬레이션으로는 절대 나오지 않았을 버그라는 점을 강조.


[S13] 재실 판정 - 잘못 묶으면 조용히 망가진다
--------------------------------------------------------------------------------
제목: 항상 켜져 있는 기기는 재실을 알려주지 못한다
핵심: '가장 오래 붙어있는 기기'가 아니라 '드나드는 기기'를 골라야 한다.
본문:
  - 3단 축퇴: 등록(REGISTER) -> 자동 학습 -> 임의 단말
  - 자동 학습 규칙: 이탈·복귀가 3회 이상 관측된 단말만 자격 인정
  - 이유: TV·거치 태블릿을 고르면 영구히 "재실"이 되어 경보가 무력화됨
  - 등록 시 후보가 2대 이상이면 추측하지 않고 거부 (실기에서 오등록 재현 후 수정)
  - 설치용 트리거는 보드의 BOOT 버튼 재활용 = 부품비 0원
말할 것:
  - 실기에서 실제로 엉뚱한 기기가 등록됐고, 그게 겉으로는 정상으로 보였다는
    점이 이 슬라이드의 핵심. "조용한 실패"를 어떻게 막았는지의 사례.

[S14] 검증 현황과 한계 - 정직하게
--------------------------------------------------------------------------------
제목: 무엇이 되고, 무엇이 아직 안 되는가
핵심: 되는 것과 하기로 한 것을 섞어서 말하지 않는다.
본문:
  검증 완료
    - ESP32 단독 엣지 파이프라인 실동작 (CSI 취득 -> 판정 -> 알림)
    - 실시간 상태 전이 ACTIVE -> NO_RESPONSE -> SLEEP_NORMAL 관측
      (peak 0.300Hz, 독립 경로인 자기상관 0.27~0.33Hz와 상호 검증)
    - 적응형 baseline 실시간 갱신, FAULT/EMERGENCY 분리
    - 재실 판정 3단 구조, NVS 학습 복원, 등록 거부 로직
  한계
    - 감지 거리 1~2m. 실사용에는 외장 안테나 또는 다중 노드 필요
    - 데이터 137윈도우·단일 피험자. 통계적 일반화 부족
    - 2.4GHz 간섭에 취약
    - 원격 알림 미구현 (현재 로컬 LED·부저 한정)
말할 것:
  - 한계를 먼저 말하면 질의응답이 훨씬 편해진다. 심사위원이 찾아낼 것을
    우리가 먼저 말하는 편이 낫다.


[S15] 마무리
--------------------------------------------------------------------------------
제목: 8시간을 60초로
핵심: 카메라 없이, 착용 없이, 2만원으로.
본문:
  - 기존 PIR 기반 서비스의 8시간 지연 -> 호흡 직접 관측으로 60초
  - 전용 레이더의 기능을 범용 WiFi 칩으로 재현
  - 다음 단계: 원격 알림(MQTT/FCM), 다수 피험자 데이터, 감지 거리 개선
말할 것:
  - 마지막 문장도 상황으로 닫는다.
    "주무시는 건지 쓰러지신 건지, 이제 60초면 압니다."


================================================================================
부록. 예상 질문과 답변 준비
================================================================================

Q. 이미 국가가 하는 서비스 아닌가?
A. 맞다. 원리도 거의 같다. 차이는 부품 단가(3만~15만원 vs 3천~7천원)와
   범용 부품 재활용 가능성이다. S8에서 먼저 인정하고 들어간다.

Q. WiFi로 사람을 보면 그것도 사생활 침해 아닌가?
A. 영상·음성을 수집하지 않는 것은 사실이나, CSI로 보행 패턴 등을 간접 추정하는
   연구가 존재한다. "원천적으로 불가능하다"고 답하지 말 것.
   현재 시스템이 그런 정보를 저장·전송하지 않는다는 사실만 답한다.

Q. 감지 거리가 1~2m면 실용성이 없지 않나?
A. 인정한다. 침대 단위 커버가 현재 한계이며, 외장 안테나와 다중 노드가
   후속 과제다. 다만 침실·침대는 사고 빈발 공간이라 우선순위가 높다.

Q. 피험자 1명 데이터로 성능을 주장할 수 있나?
A. 주장하지 않는다. 분류기 결과는 개념 증명 수준이라고 보고서에 명시했다.
   현재 주 판정 경로는 학습 분류기가 아니라 규칙 기반 신호처리다.

Q. 87% 라는 수치는 무엇인가?
A. 시스템 정확도가 아니라 PC 구현과 임베디드 구현의 '구현 동등성'이다.
   혼동되지 않도록 슬라이드에는 넣지 말 것. 물어보면 그때 설명한다.

Q. 폰을 두고 외출하면?
A. 재실로 오판한다. 다만 이는 경보를 놓치는 방향이 아니라 과잉 경보 방향이라
   안전한 실패다. 설계 전반이 "불확실하면 재실로 간주"하도록 되어 있다.
